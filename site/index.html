🧟 DESKTOP 3D GAME + MODS — مثل L4D2

DEADZONE: Survivors

لعبة تصويب زومبي ثلاثية الأبعاد للكمبيوتر (Waves FPS) — خرائط وأسلحة وزومبي قابلة للتوسعة بنظام مودات كامل: مجلدات + ملفات .dzm مثل VPK في Left 4 Dead 2.

▶ يعمل على Desktop عبر Python + Ursina pip install -r requirements.txt && python main.py

🎮 أسلوب اللعب L4D2-like wave survival

🌊 موجات زومبي

موجات متصاعدة: Common وRunner وBrute وSpitter — وبعدها وضع Endless بأعداد متزايدة.

🔫 4 أسلحة أساسية

Pistol وSMG وShotgun وRifle — ضرر ومخزن وسرعة إطلاق لكل سلاح، قابلة للتعديل بالمودات.

🗺️ خريطتان أصليتان

Rooftop Siege وAbandoned Warehouse — إحداثيات spawn ونقاط تغطية لكل خريطة.

🧩 نظام المودات mods/ — مثل VPK / Workshop

الملفالوظيفة
mod.jsonالاسم والإصدار والكاتب والأولوية priority
weapons.jsonأسلحة جديدة أو تعديل أسلحة موجودة
zombies.jsonأنواع زومبي جديدة (HP / سرعة / ضرر)
maps.jsonخرائط جديدة كاملة (props + waves)
hooks.pyسكربت مثل VScript: on_wave_start وmodify_damage
python main.py --list-mods # عرض المودات python main.py --map neon_arena # خريطة من مود python tools/new_mod.py my_gun --pack # مود جديد + ملف .dzm للمشاركة
